# Telegram Folder Broadcaster

Скрипт для рассылки сообщений по всем чатам выбранной папки Telegram с возможностью запускать несколько повторов с задержкой, кратной часу.

## Возможности

- Выбор папки Telegram по названию (используются пользовательские фильтры/папки).
- Рассылка одного и того же сообщения во все чаты папки.
- Планирование нескольких запусков с шагом в один час (например, `0 12 24`).
- Режим предварительного просмотра (`--dry-run`).

## Установка

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Получите `api_id` и `api_hash` в [кабинете разработчика Telegram](https://my.telegram.org/apps).

3. Создайте файл `.env` в корне проекта и укажите учетные данные:

   ```dotenv
   TELEGRAM_API_ID=123456
   TELEGRAM_API_HASH=abcdef1234567890abcdef1234567890
   TELEGRAM_SESSION=broadcast_session  # опционально, имя файла сессии
   ```

## Использование

```bash
python broadcast.py "Текст сообщения" "Название папки" --delays 0 12 24
```

- `Текст сообщения` — сообщение, которое получат чаты.
- `Название папки` — название папки Telegram (как в клиенте).
- `--delays` — список задержек в часах (0-24). Можно указать одну или несколько.

Дополнительные параметры:

- `--dry-run` — показать список чатов, не отправляя сообщение.
- `--session` — имя/путь файла сессии Telethon. По умолчанию используется значение из `.env` или `broadcast`.
- `--api-id` и `--api-hash` — можно указать напрямую, если не хотите хранить в `.env`.

Во время первого запуска Telethon попросит ввести код подтверждения и пароль 2FA (если включен). После этого сессия будет сохранена в файл.

## Ограничения

- Скрипт работает только с чатами, которые уже добавлены в указанную папку Telegram.
- Отправка сообщений происходит последовательно; при большом числе чатов может потребоваться больше времени.
- Убедитесь, что учетная запись соблюдает лимиты Telegram и не нарушает правила сервиса.
