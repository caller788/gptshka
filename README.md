# Telegram Folder Broadcaster

Скрипт для рассылки сообщений по всем чатам выбранной папки Telegram с возможностью запускать несколько повторов с задержкой, кратной часу.

## Возможности

- Выбор папки Telegram по названию (используются пользовательские фильтры/папки).
- Рассылка одного и того же сообщения во все чаты папки.
- Планирование нескольких запусков с шагом в один час (например, `0 12 24`).
- Встроенный графический интерфейс для ручного запуска рассылки.
- Режим предварительного просмотра (`--dry-run`).
- Пауза в 30 секунд перед отправкой каждого сообщения, чтобы снизить нагрузку на аккаунт.
- Возможность остановить активную рассылку из интерфейса.
- Защита запуска одноразовым ключом доступа.

## Установка

1. **Установите Python и Git.** Скрипт протестирован с Python 3.10+, но должен работать и на более новых версиях.

2. **Склонируйте репозиторий и перейдите в директорию проекта:**

   ```bash
   git clone <url-репозитория>
   cd gptshka
   ```

3. **(Опционально) Создайте и активируйте виртуальное окружение:**

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   ```

4. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

   > Если пакет `python-dotenv` недоступен (например, при ручной установке только `telethon`),
   > скрипт продолжит работать, но будет использовать только переменные окружения. В этом
   > случае убедитесь, что `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и `TELEGRAM_SESSION` заданы
   > системно или через параметры запуска.

5. **Получите ключи Telegram API** (`api_id` и `api_hash`) в [кабинете разработчика Telegram](https://my.telegram.org/apps).

6. **Создайте файл конфигурации `.env`:**

   ```bash
   cp .env.example .env
   ```

   Откройте `.env` любым редактором и укажите значения своих `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, а при необходимости измените имя файла сессии (`TELEGRAM_SESSION`). Здесь же можно заранее настроить путь к файлу одноразовых ключей, добавив `BROADCAST_KEYS_FILE=/полный/путь/к/keys.txt`. Чтобы пользователь не вводил ключ повторно, задайте и путь к локальному хранилищу подтвержденных ключей — например, `BROADCAST_KEYS_CACHE=/полный/путь/к/keys.txt.accepted`.

## Настройка одноразовых ключей

Чтобы передать программу безопасно, каждый запуск защищен одноразовым ключом, который удаляется из файла после использования.

1. **Создайте файл хешей ключей.** Для каждого ключа выполните:

   ```bash
   python - <<'PY'
   import hashlib

   raw_key = "YOUR_ONE_TIME_KEY"
   print(hashlib.sha256(raw_key.encode("utf-8")).hexdigest())
   PY
   ```

   Скопируйте напечатанный хеш в файл, например `keys.txt`. Для удобства можно хранить каждый хеш на новой строке и добавлять комментарии, начиная с `#`.

2. **Укажите путь к файлу с хешами.** Добавьте в `.env` строку `BROADCAST_KEYS_FILE=/полный/путь/к/keys.txt`. При необходимости можно передать путь через параметр `--keys-file`.

3. **Раздавайте ключи пользователям.** Передайте им исходные (не хешированные) ключи и попросите вводить их при запуске GUI или передавать через CLI параметр `--access-key`. После успешного запуска ключ удалится из файла, а его хеш запишется в локальный кэш на компьютере пользователя.

4. **Повторные запуски не требуют ввода ключа.** Когда хеш сохранен в кэше (`BROADCAST_KEYS_CACHE` или файл вида `keys.txt.accepted` рядом с основным хранилищем), программа найдет его автоматически. Если кэш удалить, потребуется ввести новый ключ.

## Использование (CLI)

```bash
python broadcast.py "Текст сообщения" "Название папки" --delays 0 12 24
```

- `Текст сообщения` — сообщение, которое получат чаты.
- `Название папки` — название папки Telegram (как в клиенте).
- `--delays` — список задержек в часах (0-24). Можно указать одну или несколько.

Дополнительные параметры:

- `--dry-run` — показать список чатов, не отправляя сообщение.
- `--session` — имя/путь файла сессии Telethon. По умолчанию используется значение из `.env` или `broadcast`.
- `--api-id` и `--api-hash` — можно указать напрямую, если не хотите хранить в `.env`.
- `--access-key` — одноразовый ключ доступа. Если не передавать параметр, значение берется из переменной `ACCESS_KEY`.
- `--keys-file` — путь к файлу с хешами ключей. По умолчанию используется `BROADCAST_KEYS_FILE` из окружения.
- `--keys-cache` — где хранить хеши подтвержденных ключей локально. По умолчанию используется `BROADCAST_KEYS_CACHE` или файл `<keys-file>.accepted`.
- Перед отправкой в каждый чат добавляется пауза в 30 секунд. Если нужно прервать выполнение, используйте `Ctrl+C` в консоли.

Во время первого запуска Telethon попросит ввести код подтверждения и пароль 2FA (если включен). После этого сессия будет сохранена в файл.

## Графический интерфейс

Для запуска приложения с визуальным интерфейсом выполните:

```bash
python broadcast_gui.py
```

В окне программы:

- Введите сообщение для рассылки и название папки Telegram.
- При необходимости измените имя файла сессии и укажите `API ID`/`API Hash` (иначе будут взяты значения из `.env`).
- Укажите одноразовый ключ доступа (или оставьте поле пустым, если ключ уже вводили ранее на этом компьютере). Путь к файлу ключей можно оставить пустым, если он уже прописан в `.env`. Рядом можно указать собственный путь для хранения подтвержденного ключа, иначе используется файл `<keys-file>.accepted`.
- Выберите часы запуска рассылки в списке (удерживайте `Ctrl` или `Shift` для выбора нескольких значений). Если не выбрать ничего, сообщение отправится сразу.
- Отметьте галочку «Тестовый прогон», чтобы просто посмотреть список чатов без отправки сообщений.
- Нажмите «Запустить», чтобы начать процесс. Журнал выполнения появится в нижней части окна.
- Нажмите «Остановить», чтобы досрочно прервать текущую рассылку.

## Сборка .exe с помощью PyInstaller

1. Установите PyInstaller (можно добавить в виртуальное окружение):

   ```bash
   pip install pyinstaller
   ```

2. Соберите исполняемый файл с графическим интерфейсом:

   ```bash
   pyinstaller --onefile --windowed broadcast_gui.py
   ```

   Готовый `.exe` появится в папке `dist`. Чтобы приложение работало, рядом с ним должны лежать файл сессии Telethon и `.env` (если используется для хранения ключей).

3. Для консольной версии используйте:

   ```bash
   pyinstaller --onefile broadcast.py
   ```

   Такой вариант откроет консольное окно с логом работы.

## Ограничения

- Скрипт работает только с чатами, которые уже добавлены в указанную папку Telegram.
- Отправка сообщений происходит последовательно; при большом числе чатов может потребоваться больше времени.
- Убедитесь, что учетная запись соблюдает лимиты Telegram и не нарушает правила сервиса.
